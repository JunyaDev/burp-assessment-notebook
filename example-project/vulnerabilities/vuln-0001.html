FINDING // vuln-0001

TitleReflected XSS via search parameter q
SeverityHIGH
StatusConfirmed
Affected URLhttps://portal.acme.test/search
Componentsearch form, parameter q

DESCRIPTION

The q parameter is reflected into the HTML response without output encoding, allowing script injection.

TECHNICAL OBSERVATION

A canary value appeared verbatim in HTML text context.

STEPS TO REPRODUCE

1. Submit q=<script>alert(1)</script> on /search.
2. Observe the script executes in the response.

IMPACT

Session theft, actions performed as the victim.

REMEDIATION

Context-aware output encoding; a strict Content-Security-Policy.
